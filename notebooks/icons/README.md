# Weather icons

Icons for the MeteoSwiss weather symbol codes used in the OGD local forecast
(`jp2000d0` daily, `jww003i0` 3-hourly): codes 1–42 (day) and 101–142 (night).

- `png/64/<code>.png` – 64×64 px icons, transparent background
- `symbols.json` – code → day/night flag and DE/FR/IT/EN descriptions

The icons are an original set drawn for this repository and keyed to the
meaning of each code. They are **not** the official MeteoSwiss pictograms.
The descriptions are the official texts from the MeteoSwiss pictogram
reference file (version of 14 February 2022).
